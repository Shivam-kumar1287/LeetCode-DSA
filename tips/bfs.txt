Breadth First Search (BFS) in Binary Tree — Complete Guide
What is BFS?

BFS (Breadth First Search) traverses nodes:
level by level
left to right

It explores:
all nearby nodes first before going deeper.

Main Idea
DFS → goes deep first
BFS → goes level wise

Visualization
Binary Tree:

        1
      /   \
     2     3
    / \   / \
   4  5  6  7

BFS Traversal:

1 → 2 → 3 → 4 → 5 → 6 → 7

Output:
1 2 3 4 5 6 7

Important Concept
BFS uses:

Queue
Because queue works on:

FIFO
First In First Out
Why Queue?

Because:

first inserted node processed first
perfect for level traversal
BFS Algorithm
Steps
Put root into queue
Remove front node
Print/process it
Add its children
Repeat until queue empty
BFS Java Code
import java.util.*;

class Node {

    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
    }
}

public class Main {

    static void bfs(Node root) {

        if(root == null)
            return;

        Queue<Node> q = new LinkedList<>();

        q.offer(root);

        while(!q.isEmpty()) {

            Node curr = q.poll();

            System.out.print(curr.data + " ");

            if(curr.left != null) {
                q.offer(curr.left);
            }

            if(curr.right != null) {
                q.offer(curr.right);
            }
        }
    }

    public static void main(String[] args) {

        Node root = new Node(1);

        root.left = new Node(2);
        root.right = new Node(3);

        root.left.left = new Node(4);
        root.left.right = new Node(5);

        root.right.left = new Node(6);
        root.right.right = new Node(7);

        bfs(root);
    }
}
Output
1 2 3 4 5 6 7

BFS Time Complexity

For Binary Tree:

O(N)

Because every node visited once.

Space Complexity
O(N)

Worst case:
queue stores one entire level.

BFS vs DFS
Feature	BFS	DFS
Uses	Queue	Stack/Recursion
Traversal	Level wise	Depth wise
Shortest Path	Yes	No
Memory	More	Less
Good For	Minimum distance	Backtracking
Level Order Traversal

BFS in tree is also called:

Level Order Traversal
Level Wise BFS

Output each level separately.

Example
Level 1 → 1
Level 2 → 2 3
Level 3 → 4 5 6 7
Java Code (Level Order)
import java.util.*;

class Node {

    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
    }
}

public class Main {

    static void levelOrder(Node root) {

        Queue<Node> q = new LinkedList<>();

        q.offer(root);

        while(!q.isEmpty()) {

            int size = q.size();

            for(int i=0; i<size; i++) {

                Node curr = q.poll();

                System.out.print(curr.data + " ");

                if(curr.left != null)
                    q.offer(curr.left);

                if(curr.right != null)
                    q.offer(curr.right);
            }

            System.out.println();
        }
    }

    public static void main(String[] args) {

        Node root = new Node(1);

        root.left = new Node(2);
        root.right = new Node(3);

        root.left.left = new Node(4);
        root.left.right = new Node(5);

        root.right.left = new Node(6);
        root.right.right = new Node(7);

        levelOrder(root);
    }
}
Output
1
2 3
4 5 6 7

# 🔥 STRING CHEAT SHEET — JAVA + PYTHON

## 1. 🔥 Convert String → Char Array

### Java

```java
String s = "hello";

char[] arr = s.toCharArray();
```

### Result

```text
s   = "hello"

arr = ['h', 'e', 'l', 'l', 'o']
```

### Python

```python
s = "hello"

arr = list(s)
```

### Result

```text
arr = ['h', 'e', 'l', 'l', 'o']
```

# 3. 🔥 Frequency Array Trick — Very Fast

Useful when characters are only lowercase `a-z`.

## Java

```java
String s = "banana";

int[] freq = new int[26];

for (int i = 0; i < s.length(); i++) {
    freq[s.charAt(i) - 'a']++;
}
```

### How it works

```text
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
...
'z' - 'a' = 25
```

For:

```text
s = "banana"
```

Frequency:

```text
a → 3
b → 1
n → 2
```

So:

```text
freq[0] = 3   // a
freq[1] = 1   // b
freq[13] = 2  // n
```

### Increase / Decrease

```java
freq[s.charAt(i) - 'a']++;
```

Means:

```text
frequency + 1
```

And:

```java
freq[s.charAt(i) - 'a']--;
```

Means:

```text
frequency - 1
```

### Python

```python
s = "banana"

freq = [0] * 26

for i in range(len(s)):
    freq[ord(s[i]) - ord('a')] += 1
```

### Result

```text
a → 3
b → 1
n → 2
```

# 4. 🔥 Keep Only Letters

## Java — Regex

```java
String s = "A man, a plan, a canal: Panama";

String result = s.replaceAll("[^a-zA-Z]", "");
```

### Result

```text
Original:
"A man, a plan, a canal: Panama"

Result:
"AmanaplanacanalPanama"
```

If you also want lowercase:

```java
String result = s.replaceAll("[^a-zA-Z]", "").toLowerCase();
```

### Result

```text
"amanaplanacanalpanama"
```

## Python

```python
s = "A man, a plan, a canal: Panama"

result = "".join(ch for ch in s if ch.isalpha())
```

### Result

```text
"AmanaplanacanalPanama"
```

For lowercase:

```python
result = "".join(ch for ch in s if ch.isalpha()).lower()
```

### Result

```text
"amanaplanacanalpanama"
```

# 5. 🔥 Remove Spaces

## 5.1 Remove spaces from both ends → `trim()`

### Java

```java
String str = "  hello world  ";

str = str.trim();

char[] arr = str.toCharArray();
```

### Result

```text
str = "hello world"

arr = ['h','e','l','l','o',' ','w','o','r','l','d']
```

⚠️ `trim()` removes spaces from the **beginning and end**, not spaces in the middle.

---

# 5.2 Remove ALL normal spaces → `replace()`

```java
String str = "  hello world  ";

str = str.replace(" ", "");

char[] arr = str.toCharArray();
```

### Result

```text
"  hello world  "

        ↓

"helloworld"
```

---

# 5.3 Remove ALL whitespace → `replaceAll()`

Useful for:

```text
space
tab
newline
```

### Java

```java
String str = "  hello \t world \n";

str = str.replaceAll("\\s+", "");

char[] arr = str.toCharArray();
```

### Result

```text
"  hello \t world \n"

        ↓

"helloworld"
```

### Quick Difference

| Method                   | What it does                      |
| ------------------------ | --------------------------------- |
| `trim()`                 | Removes spaces from beginning/end |
| `replace(" ", "")`       | Removes normal spaces everywhere  |
| `replaceAll("\\s+", "")` | Removes all whitespace            |

# 6. 🔥 Java `split()` Cheat Sheet

`split()` converts:

```text
String → String[]
```

---

## 6.1 Split by single space

```java
String str = "hello world java";

String[] arr = str.split(" ");
```

### Result

```text
["hello", "world", "java"]
```

---

## 6.2 Split by multiple spaces ⭐

```java
String str = "hello    world   java";

String[] arr = str.trim().split("\\s+");
```

### Result

```text
["hello", "world", "java"]
```

⭐ Very useful for coding questions involving sentences.

---

## 6.3 Split by comma

```java
String str = "apple,banana,mango";

String[] arr = str.split(",");
```

### Result

```text
["apple", "banana", "mango"]
```

---

## 6.4 Split by comma + optional spaces

```java
String str = "apple, banana,  mango";

String[] arr = str.split("\\s*,\\s*");
```

### Result

```text
["apple", "banana", "mango"]
```

---

## 6.5 Split by dot ⚠️

`.` has a special meaning in Regex.

❌ Don't use:

```java
str.split(".");
```

✅ Use:

```java
String str = "hello.world.java";

String[] arr = str.split("\\.");
```

### Result

```text
["hello", "world", "java"]
```

---

## 6.6 Split by pipe `|` ⚠️

`|` is also special in Regex.

```java
String str = "java|python|cpp";

String[] arr = str.split("\\|");
```

### Result

```text
["java", "python", "cpp"]
```

---

## 6.7 Split by hyphen

```java
String str = "10-20-30";

String[] arr = str.split("-");
```

### Result

```text
["10", "20", "30"]
```

---

## 6.8 Split by slash

```java
String str = "10/20/30";

String[] arr = str.split("/");
```

### Result

```text
["10", "20", "30"]
```

# 21. 🔥 Regex Quick Revision

```text
" "           → single space

"\\s+"        → one or more whitespace

","           → comma

"\\."         → dot

"\\|"         → pipe |

"-"           → hyphen

"/"           → slash

"\\d+"        → one or more digits

"\\D+"        → one or more non-digits

"[a-zA-Z]+"   → one or more letters

"\\W+"        → one or more non-word characters

"[,;|]"       → comma OR semicolon OR pipe

"[,\\s]+"     → comma OR whitespace
```

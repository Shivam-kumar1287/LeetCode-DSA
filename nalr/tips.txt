# Geometry & Mensuration

## 3D Shapes
| Shape              | Volume (V)        | Total Surface Area (TSA) | Diagonal        | LSA / CSA / Extra                   |
| ------------------ | ----------------- | ------------------------ | --------------- | ----------------------------------- |
| **Cube**           | a³                | 6a²                      | √3 a            | LSA = 4a²                           |
| **Cuboid**         | lbh               | 2(lb + bh + hl)          | √(l² + b² + h²) | LSA = 2h(l + b)                     |
| **Cylinder**       | πr²h              | 2πr(h + r)               | ❌               | CSA = 2πrh                          |
| **Cone**           | ⅓ πr²h            | πr(l + r)                | ❌               | l = √(r² + h²), CSA = πrl           |
| **Sphere**         | 4/3 πr³           | 4πr²                     | ❌               | —                                   |
| **Hemisphere**     | 2/3 πr³           | 3πr²                     | ❌               | CSA = 2πr²                          |
| **Frustum (Cone)** | ⅓πh(R² + r² + Rr) | π(R² + r² + l(R + r))    | ❌               | l = √((R−r)² + h²), CSA = πl(R + r) |
| **Pyramid**        | ⅓Bh               | LSA + Base Area          | ❌               | LSA = ½ × Perimeter × l             |

## 2D Shapes & Extra Concepts
- **Weight** = Volume × density
- **Radius of inscribed sphere in a cone**: r = Rh / (l + R)
- **Circumference of cylinder base**: 2πr
- **Diagonal of square**: d = s√2
- **Rectangle diagonal**: d = √(l² + b²)
- **Perimeter of rectangle**: P = 2(l + b)

## Triangles
| Type / Case                     | Area Formula                      | Extra / Condition       |
| ------------------------------- | --------------------------------- | ----------------------- |
| **Basic Triangle**              | ½ × base × height                 | Height ⟂ base           |
| **Right Triangle**              | ½ × base × height                 | Base ⟂ height           |
| **Equilateral Triangle**        | √3/4 × a²                         | All sides equal         |
| **Isosceles Triangle**          | ½ × b × h                         | Height bisects base     |
| **Heron’s Formula**             | √[s(s−a)(s−b)(s−c)]               | s = (a+b+c)/2           |
| **Using Trigonometry**          | ½ ab sinC                         | Angle between a & b     |
| **Using Coordinates**           | ½ \|x₁(y₂−y₃)+x₂(y₃−y₁)+x₃(y₁−y₂)\| | For coordinate geometry |
| **Area using inradius (r)**     | A = r × s                         | s = semi-perimeter      |
| **Area using circumradius (R)** | A = abc / (4R)                    | a, b, c = sides         |

- **Semi-perimeter**: s = (a + b + c) / 2
- **Height of equilateral triangle**: h = √3/2 a

# Algebra Tricks

- **Squares & Higher Powers**: 
  - If x + 1/x = n, then:
  - x² + 1/x² = n² - 2
  - x³ + 1/x³ = n³ - 3n
- **Power trick**: x^631 + 1/x^631 = 11 then find value of x^631 - 1/x^631 = √(11² - 4) = √(121 - 4) = √117
- **Expression**: a² + b² + c² - ab - bc - ca
  - Trick: Result = 3 × d² (where d is the common difference)
- **Expression**: a³ + b³ + c³ - 3abc
  - If given AP terms like a=64, b=66, c=68
  - Trick: 9 × d² × m (where d = difference, m = middle value)
  - Example: 9 × 2² × 66

# Logarithms

| Formula Name       | Formula                                            | Shortcut Idea             |
| ------------------ | -------------------------------------------------- | ------------------------- |
| Definition         | log_a(b) = x ⟺ a^x = b                              | Convert log to exponent   |
| Product Rule       | log_a(xy) = log_a(x) + log_a(y)                    | Multiplication → Addition |
| Division Rule      | log_a(x/y) = log_a(x) - log_a(y)                   | Division → Subtraction    |
| Power Rule         | log_a(x^n) = n·log_a(x)                            | Power comes front         |
| Root Rule          | log_a(ⁿ√x) = (1/n)·log_a(x)                        | Root → Fraction           |
| Change of Base     | log_a(b) = log_c(b) / log_c(a)                     | Change base easily        |
| Reciprocal Rule    | log_a(b) = 1 / log_b(a)                            | Reverse base/value        |
| Log of 1           | log_a(1) = 0                                       | Any base power 0 = 1      |
| Log of Same Number | log_a(a) = 1                                       | Same base/value           |
| Exponential Cancel | log_a(a^x) = x                                     | Log & base cancel         |
| Reverse Cancel     | a^(log_a(x)) = x                                   | Power & log cancel        |
| Equality Rule      | If log_a(x) = log_a(y), then x = y                 | Bases same ⇒ values same  |
| Common Log         | log_10(x) or log(x)                                | Base 10                   |
| Natural Log        | ln(e) = 1                                          | Base e                    |

# Time, Speed & Distance

| Concept                             | Formula                                                                         |
| ----------------------------------- | ------------------------------------------------------------------------------- |
| Speed                               | Speed = Distance ÷ Time                                                         |
| Distance                            | Distance = Speed × Time                                                         |
| Time                                | Time = Distance ÷ Speed                                                         |
| Average Speed                       | Average Speed = Total Distance ÷ Total Time                                     |
| Convert km/hr to m/s                | Multiply by (5/18)                                                              |
| Convert m/s to km/hr                | Multiply by (18/5)                                                              |
| Time taken to cross a pole/object   | Length of train ÷ Speed of train                                                |
| Time taken to cross platform        | (Length of train + Length of platform) ÷ Speed                                  |
| Speed after changing time           | New Speed = (Old Speed × Old Time) / New Time                                   |
| If speed increases by x%            | Time decreases by (x / (100+x)) × 100%                                          |
| If speed decreases by x%            | Time increases by (x / (100-x)) × 100%                                          |
| Boats & Streams – Downstream Speed  | Boat Speed + Stream Speed                                                       |
| Boats & Streams – Upstream Speed    | Boat Speed − Stream Speed                                                       |
| Boat Speed in Still Water           | (Downstream Speed + Upstream Speed) / 2                                         |
| Stream Speed                        | (Downstream Speed − Upstream Speed) / 2                                         |

- **Average Speed**: 2ab / (a + b) (when distances are equal)
- **Distance**: (S₁ × S₂) / |S₁ - S₂| × Time Difference
- **Length of Train**: Speed × Time

### Relative Speed
| Movement Direction | Visual Concept | Mathematical Formula |
| ------------------ | -------------- | -------------------- |
| Same Direction     | ⟶ and ⟶ Overtaking / Catching up | Relative Speed = V₁ - V₂ (if V₁ > V₂) |
| Opposite Direction | ⟶ and ⟵ Approaching / Moving apart | Relative Speed = V₁ + V₂ |

# Binary Tree Tips & Notes
*   **Basics:** Root, left child, right child.

### Theoretical & Coding Tips
*   **Tip:** Most tree problems use DFS (Recursion) or BFS (Queue).
*   **DFS Code Pattern:**
    ```java
    public void dfs(TreeNode node) {
        if (node == null) return;
        // Pre-order logic
        dfs(node.left);
        // In-order logic
        dfs(node.right);
        // Post-order logic
    }
    ```
*   **BFS Code Pattern (Level Order Traversal):**
    ```java
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            TreeNode curr = q.poll();
            if (curr.left != null) q.offer(curr.left);
            if (curr.right != null) q.offer(curr.right);
        }
    }
    ```
*   **Tip:** When working with Binary Search Trees (BST), checking `isValidBST` requires carrying the bounds down.

### Time & Space Complexity
*   **Traversal (DFS/BFS):** O(N) Time, where N is the number of nodes (we visit each node once).
*   **Search/Insert/Delete in standard Binary Tree:** O(N) Time.
*   **Search/Insert/Delete in balanced BST (e.g., AVL, Red-Black):** O(log N) Time.
*   **Space Complexity (DFS):** O(H) where H is the height of the tree due to recursion stack. Worst case O(N) for a skewed tree, Best case O(log N) for a balanced tree.
*   **Space Complexity (BFS):** O(W) where W is the maximum width of the tree. In the worst case (perfect tree), the lowest level holds N/2 nodes, so O(N).
